# Domain Documentation

This repository uses a **single-context** layout for domain documentation.

## Instructions for Agents

- Read from `CONTEXT.md` at the repository root for general domain knowledge and context.
- Architecture Decision Records (ADRs) are stored in the `docs/adr/` directory.
- Always consult these files when seeking domain context, business rules, or historical architectural decisions.
- When creating a new ADR, save it in `docs/adr/` following standard conventions.
