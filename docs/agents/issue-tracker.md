# Issue Tracker

Issues for this repository are tracked in **GitHub Issues**.

Skills like `to-tickets`, `triage`, `to-spec`, and `qa` should read from and write to this tracker.

## Instructions for Agents

- Use the `gh` CLI to interact with issues (e.g., `gh issue create`, `gh issue view`, `gh issue list`, `gh issue comment`).
- Ensure all created issues are concise, actionable, and properly labeled.

## Configuration

- **PRs as a request surface**: false
